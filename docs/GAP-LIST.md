## Explicit non-goals of this skeleton (Lead decision 2026-10-29)

- No iOS16/Darwin22 target: the profile is the proven official iPadOS 17.7.11-21H461. The
  `proposals/profiles/os/ios-16.7.16-20H392/` directory is a reference-only public skeleton
  (picasso, `abi_qualified=false`) kept for traceability.
- No route 2 (ios-sweet shim / hackios resident loader) files are used here; the C-line report is
  in `agents/c-ios16-star/REPORT-C-IOS16-STAR.md`.
- No device operations and no flashing instructions in this repository.
